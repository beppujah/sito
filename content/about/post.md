I am Giuseppe Zamboni, DIY enthusiast, artistic thinker and techical recycler from Italy, based in Czechia. 

This website is an attempt to make a record of my work in a free and comfortable environment, but also a place to post some randomness.

The app that runs the site is made with Claude LLM and it’s code is avaliable at the  github repository [github.com/beppujah/sito](https://github.com/beppujah/sito)

Yes, it is made with AI. But that doesn’t mean I didn’t make it. If I make a wooden desk with a saw, should I say the saw made it?
I could have made a war drone, or a crypto speculative app, but I made this instead.
(and this should solve the controversy about AI usage for creative purposes)

The website is managed via browser with an editor page, where to upload media and change viewing settings.
For more info and instruction how to use it for your own project, check the repo.

If you want to support my work, you can buy me a [coffee](https://ko-fi.com/beppujah)
